💙 Brother's Digital Greeting Card
A beautiful, responsive, and animated digital greeting card built with HTML5, CSS3, and JavaScript. This project features smooth entry animations, a pulsing heartbeat effect, and an interactive music trigger.

✨ Features:
Smooth Animations: Uses CSS @keyframes for a "pop-in" entry effect.

Animated Heart: A pulsing heartbeat effect using CSS transforms.

Responsive Design: Fully optimized for mobile, tablet, and desktop screens.

Interactive Audio: A "Surprise" button that triggers a background song.

Modern UI: Features a soft blue gradient background and a clean card layout.

🚀 Getting Started
To get this card running on your local machine, follow these simple steps:

1. Clone the repository
Bash
git clone https://github.com/your-username/brothers-card.git
2. Add your Media
For the code to work, you need to add your own media files to the root folder:

Photo: Rename your image to brother.jpeg.

Music: Rename your audio file to song.mp3.

3. Run the project
Simply double-click the index.html file to open it in your favorite web browser.
